## 2. 최종 모델

`hj19_tmcb.zip` · 86파일 · 추론 68초 (한도 600초)

```
z  = mean(코어 LGBM 20)                        4변형 × 5시드, num_leaves ×2
z  = (1−0.75)·z + 0.75·(0.875·emb4 + 0.125·noid)   MLP 8멤버
z += 0.75 · 0.05 · (compact_context − baseline_noid)
z[R] = 0.9525·z[R] + 0.0475·zg[R]              일반 LGBM 12 라우팅
z[F] = 0.6700·z[F] + 0.3300·zf[F]              F 전문가 라우팅
z  = (1−0.10)·z + 0.10·mean(CatBoost 12)
z += logit_adjust(...)                          사후 δ 8축
p  = σ(z + logit_delta)
p  = 0.4801 + 1.05·(p − 0.4801) + PROB_SHIFT   확률공간 아핀
p[R∧covered] += 0.10 · tmcb_corr                TrackMan CatBoost 잔차 브랜치
```

### 핵심 구조

- **`pitcher_id` 임베딩 8차원 + 콜드스타트 패치.** 매 시즌 행의 14~22% 가 그 전에 없던
  투수인데, 그 전부가 학습 중 한 번도 갱신되지 않는 `index 0` 벡터 하나를 공유하고
  있었다 (알려진 투수 1명당 0.1% vs 미지값 1칸당 20% = **200배 과부하**).
  `index 0` 을 학습된 임베딩의 평균으로 채웠다.
- **로짓공간 선형 δ 축(`art['col']`).** 배포 78피처 어느 컬럼 위에도 `z += β(x−μ)/σ`
  를 걸 수 있는 통로. 같은 정보를 **피처로 넣으면 전이가 안 됐는데** 이 통로로는 됐다.
- **R/F 라우팅.** `game_type` 은 피처에서 드랍돼 있다 (시즌마다 뒤집혀 독이 된다).
  대신 **어느 모델에 물을지**만 가른다.
- **TrackMan 잔차 브랜치.** 추론에 트랙맨 원본이 들어가지 않는다 — 서빙은
  `tmcb_state.joblib` 정적 조회표(≤2024 · decay 0.80)다.

## 4. 이 대회에서 반복해서 값을 낸 것

**① 남의 종결을 인용하기 전에 그 실험의 팔 정의를 직접 연다.**
`pitcher_id` 임베딩 차원은 "효과 없음" 으로 닫혀 있었는데, 그 판정이 **4중 교란**
(`hid 128→256` 단독 −88 · `batter_id` 동반 · dropout · weight decay)이었다.
한 칸만 바꾸니 **+7.67**. 축이 죽은 게 아니라 측정이 죽어 있었다.

**② 닫힌 축은 층이 바뀌면 다시 열린다.** 재개방으로 회수한 것이 누적 **+21.67**.
`emb8` +7.67 · `gap_reverse` +8.68 · 라우팅 +1.26 · 컬럼축 +4.06.

**③ in-sample 잔차는 방향을 반대로 가리킨다.** 챔피언이 학습한 시즌의 잔차는 진짜
구조가 아니라 과적합 잔재다. 라우팅(부호 반대 · 19.7배) · 컬럼 δ 축(배포된 두 축
모두 부호 반대)에서 확인. **평가 시즌이 in-sample 이면 홀드아웃은 발굴용이지
판정용이 아니다.**

**④ `max` 채점에서는 `P(Δ>0)` 이 아니라 `E[Δ]` 를 최적화한다.** 지는 비용이
점수가 아니라 슬롯 한 장이기 때문이다. 실측 슬롯 효율:

| 클래스 | 슬롯 | 합계 | 슬롯당 |
| --- | ---: | ---: | ---: |
| 모델 용량·구조 | 4 | +10.79 | **+2.70** |
| 신규 δ 축 | 5 | +13.07 | **+2.61** |
| 사후 상수 튜닝 | 7 | **−0.79** | **−0.11** |
| 학습된 층 | 1 | −5.93 | −5.93 |

**예측 가능성과 크기가 역상관이다** — 사후 상수 축은 이미 최적 근처라 예측이 쉽고
헤드룸이 없다. 새 통로는 헤드룸이 크고 그래서 예측 수단이 있을 수 없다.

**⑤ 같은 정보라도 넣는 자리가 결과를 가른다.** 트랙맨 물리량을 **피처**로 넣으면
전이가 안 됐고(잔차 스크린 0/33), **로짓 잔차 브랜치**로 넣으니 +2.79 였다.
컬럼 δ 축도 같다.

## 7. 채점 구조

```
score = 1e5 × (1 − Brier / (r(1−r)))     r = 평가 라벨 평균 ≈ 0.486987
K     = 1e5 / (r(1−r)) = 400,271
```

순수 레벨 이동은 닫힌 식으로 정확하다 — `ΔScore = −K[2Δ·b + Δ²]`, `b = p̄ − r`.
실측과 소수 넷째 자리까지 맞았다. 이 항등식이 확률공간 아핀 축(+18.48)의 근거다.
