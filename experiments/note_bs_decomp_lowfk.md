# 노트 — Brier 분해로 본 현재 모델의 남은 여지 (2026-08-21)

fold2024 배포형 예측을 Murphy 분해로 뜯어 "점수가 어디에 살고 있는가"를 확인한 세션 기록.
결론 한 줄: **REL(캘리브레이션)은 다 짜냈고, 남은 점수는 전부 RES(빈을 가르는 새 순서 정보)에 있다.**

---

## 1. 두 가지 BS 분해와 대응 관계

```
Murphy:   BS = REL − RES + UNC
   REL = Σ (n_k/N)(f_k − ō_k)²     예측 vs 빈의 실제율.  작을수록 좋음
   RES = Σ (n_k/N)(ō_k − ō)²      빈의 실제율 vs 전체율.  클수록 좋음
   UNC = ō(1−ō)                   데이터 상수. 못 건드림

분산형:   BS = var(p) − 2·cov(p,y) + var(y) + (p̄ − ȳ)²
   레벨 항 (p̄−ȳ)² 는 나머지와 완전히 독립
```

- 대응: **RES ↔ cov(p,y) 채널**(대가는 var(p)), **REL ↔ f_k·ō_k 불일치 + 레벨 항**, UNC = var(y).
- 대회 점수식에 넣으면 **`BSS = 100000·(RES − REL)/UNC`** — 점수는 문자 그대로 RES에서 REL을 뺀 것.
- 기호 주의: ō는 **실제 outcome(라벨)의 평균**이다. 예측 평균은 p̄(f̄). f_k−ō_k는 REL이고,
  RES에는 f_k가 **아예 안 들어간다** — f_k의 역할은 어떤 행을 같은 빈에 묶느냐뿐.

### 로짓 항 추가의 두 종류 (헷갈리면 안 되는 구분)

| 조작 | 움직이는 항 | 이유 |
| --- | --- | --- |
| 상수 로짓 시프트 (`shift_to_prior`) | 레벨 항만 | 단조 변환은 순서 불변 → ō_k 불변 → RES 원리적으로 불변 |
| 행별 로짓 항 (δ·β, jointbeta 계열) | RES ↑ (성공 시) | 순서를 바꾸는 유일한 방법. 승리 조건 `2Δcov > Δvar(p)` |

행별 항도 REL을 자동으로 낮추진 않는다 — β가 크면 overshoot가 REL로 청구된다.
β 적합 + 고원 검사가 REL 통제 장치이고, `shift_to_prior` 재고정(jointbeta9.py:90)이
레벨 항을 0으로 묶어 구조 채널만 평가하게 한다.

## 3. fold2024 배포형 예측의 십분위 분해

재구성: `fold2024_5488ef1b18.npz`(s24 지문) → `z = 0.6·z_lgb + 0.4·z_mlp` (MLP_ALPHA 0.40)
→ `shift_to_prior(σ(z), ȳ_2024)`. 사후 δ축 4개는 제외 (작은 보정항).

| | 값 | 비고 |
| --- | --- | --- |
| REL (10빈) | **0.000040** | 캘리브레이션은 거의 소진 |
| RES (10빈) | **0.002053** | 양 끝 두 빈이 RES의 **72%** |
| BSS | 분해 805.7 / 행단위 837.6 | 차이 ~32점 = 10빈으로 뭉갠 빈 내부 순서의 몫 |

- 예측 범위가 좁다: **0.341 ~ 0.618**. 최하 빈 f_k=.4156 vs ō_k=.4072, 최상 빈 .5641 vs .5782.
- 양 꼬리 모두 f_k가 ō_k보다 **안쪽**(under-sharp, ±0.008~0.014) — 전역 온도 c>1의 자리지만,
  §7.19/jointbeta 변형 C에서 fold 간 방향이 갈려 기각된 대역. 공짜 점수 아님.

### 최하 십분위(낮은 f_k)의 정체 — 표준화 평균차 d 기준

d = (최하 십분위 평균 − 나머지 90% 평균) / 전체 표준편차.

1. **투수 제구 이력이 압도적 1순위** (상위 8개 전부 `asof_pitcher_*`):
   `reverse_rate` d=+1.30 (.298 vs .231) · `success_rate` −1.17 · `prev1/3/5경기` −0.82~−1.09 ·
   `ball_rate` +0.96 · `offspeed_rate` −0.70
2. 투수 프로필: 저표본(`asof_pitcher_n` 2,773 vs 4,057), 손잡이 소수 코드 비중 26%→47%
3. 상황(부차): `balls_before` 1.27 vs 0.85, 만루 lift 1.21×, 고득점 경기
4. **game_type F lift 2.08×** — 최하 십분위의 24.6%가 F (전체의 ~12%)

→ 이 모델의 RES는 거의 전부 **투수 정체성 축**에서 나온다 (EDA 투수 축 천장과 같은 그림).
모델이 0.34 밑으로 안 내려가는 건 합리적: 하위 1%의 실제 ō도 0.39라, 극단 확률의 근거가
데이터에 없다.

## 4. "이 특징에 페널티를 주면 안 되나" → 안 된다 (이중 계상)

d 표는 모델이 **이미 아는 것**의 목록이다 (예측값으로 갈라서 잰 것이므로 인과가
"특징 → 낮은 f_k"). 같은 축으로 또 누르면:

- RES 불변 — 같은 축의 단조 함수는 순서를 거의 안 바꾼다
- REL 악화 — f_k가 ō_k를 지나치는 초과분이 그대로 (f_k−ō_k)²로 청구

**판정 기준은 "낮은 f_k와의 상관"이 아니라 "잔차(y−p)와의 상관"이다.**
플래툰 δ가 채택된 이유: `asof_*`에 손잡이 분할이 **없어서** 잔차에 신호가 남아 있었다.
`reverse_rate`는 입력 그대로라 잔차에 남은 게 없다. 34전 33패의 상당수가 이 함정.

두 명제를 항상 분리할 것:
- "X그룹의 성공률이 낮다" = f_k를 설명하는 사후 기술 → 액션 없음
- "X그룹에서 모델이 **과대/과소예측**한다" = 잔차 편향 → 보정항의 자리

## 5. 개선 방향 — 맞는 결론과 두 가지 교정

맞는 결론: REL이 소진됐으므로 남은 레버는 **순서를 바꾸는 새 행별 정보(RES)** 뿐.

- 교정 1 — 과녁은 "실력 없는 애들"이 아니라 **아직 안 갈라진 빈**. 최하 빈은 이미 가장 잘
  해낸 구간이다. 가운데 빈들(행의 60%, RES 기여 ~0)이 진짜 반반인지, 섞여서 반반으로
  보이는지가 질문이고, 후보지는 꼬리·가운데를 가리지 않는다. 탐색 기준은 잔차 상관.
- 교정 2 — "저표본/신인" 축은 §7.79–7.80(rookie 시리즈)에서 측정돼 닫혔다:
  신인−기존 스킬 차는 fold 간 부호 반대(2023 −411 / 2024 +80), 남은 건 F 신인 레벨 편향
  (t +2.1 < 통과선 3, 행의 2.5%, δ_F와 중복)뿐. 최하 빈에 저표본 투수가 몰린 건 모델이
  그들을 못 맞춰서가 아니라 저표본 자체가 낮은 f_k의 정당한 근거이기 때문.

새 정보의 3조건: ① 행마다 다르고 ② 현재 빈 안에서 변동하며 ③ y와의 관계가 시즌을 건너
지속. 원료는 train 이력의 재조합뿐이고, 채널 전수조사(MODEL.md)가 그 목록을 이미 셌다.
현재 열린 방향(투수내 기울기 → jointbeta 계열)이 교정 1의 논리와 정확히 일치.

### 대회 모델에의 함의

1. **피처 후보로서 사망** — 자체 외부검증(성적 무분리)이 이미 그렇게 말한다. 행 단위 사용
   방식 정보(`li`, `inning`)는 이미 입력에 있고, 시즌 집계형 사용량은 2025 신인의 초반
   시점에 관측 불가(as-of 위반).
2. **진짜 발견 = 생존과 성적의 해리.** 다음 시즌 생존을 가르는 건 제구 실력이 아니라
   쓰임새다. → 2025의 2년차 복귀자들이 거친 생존 선택은 **제구 스킬에 중립**이므로,
   생존자 편향에 의한 레벨 보정 채널은 없다(유용한 영결과). 개체 회전 감쇠 모형의
   선택 방향이 스킬 축과 직교함이 측정된 셈.
