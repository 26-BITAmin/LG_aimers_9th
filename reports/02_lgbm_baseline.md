# 02. LightGBM 시간 홀드아웃 기준 모델

## 목적

주최 측 Random Forest를 복제하지 않고, 대회 점수와 2025년 시간 이동에 직접 맞춘 첫 모델을 만든다.
모든 파생 피처는 현재 행과 학습 폴드에서 고정한 상수만 사용한다.

## 선택된 첫 기준 모델

- 모델: LightGBM 4.6.0
- 입력: 공식 입력 피처 + 행 단위 파생 피처
- `pitcher_id`, `batter_id`: 제외
- 학습 데이터: `game_type=R`만 사용
- 검증 데이터: 해당 시즌 전체 R/F 유지
- 시즌 가중치: 반감기 2.5년
- 트리: 500개, learning rate 0.03, num leaves 31

## 실험 결과

| 검증 시즌 | 학습 시즌 | BSS | Brier | AUC | 예측 평균 - 실제 평균 |
|---:|---|---:|---:|---:|---:|
| 2022 | 2019~2021 | 94.58 | 0.248928 | 0.53266 | -2.16%p |
| 2023 | 2019~2022 | 391.65 | 0.249021 | 0.53672 | -0.34%p |
| 2024 | 2019~2023 | **644.69** | **0.248196** | **0.54695** | +1.26%p |

2024에서 공식 수료 기준 549.51점을 넘었지만, 이 수치가 2025 리더보드 성능을 보장하지는 않는다.
2022~2024 모두 양수라는 점과 최근 두 폴드에서 성능이 개선된 점을 첫 기준선으로 사용한다.

## 2024 절제 실험

| 설정 | BSS | AUC | 해석 |
|---|---:|---:|---|
| 전체 game type + 선수 ID | 176.97 | 0.53688 | ID와 불안정한 F 패턴에 과적합 |
| R만 학습 + 선수 ID | 244.42 | 0.53664 | F 제거만으로 일부 개선 |
| R만 학습 + 선수 ID 제외 | **644.69** | **0.54695** | 공식 asof 이력이 ID보다 안정적 |

## 확인된 취약점

- 2024 `game_type=F`: BSS 114.22로 R의 671.90보다 낮다.
- `asof_pitcher_n=201~500`: BSS 110.81로 약하다.
- 신규 타자 행: BSS 536.34로 전체보다 낮다.
- 전체 예측 평균이 실제보다 1.26%p 높아 시간 드리프트 대응 여지가 있다.
- cold-start 표본은 매우 작아 개별 폴드 수치를 과해석하지 않는다.

## 다음 실험

1. LightGBM의 학습 기간·반감기·정규화 강도를 고정된 forward fold로 비교한다.
2. CatBoost를 범주형 강건성 후보로 추가하되 선수 ID 포함/제외를 모두 평가한다.
3. 각 모델의 시간 OOF 예측을 저장하고 오차 상관이 낮은 모델만 앙상블한다.
4. 보정 계수는 과거 시즌에서 학습하고 다음 시즌에 고정 적용한다.
5. 최종 설정이 정해진 뒤 2019~2024 전체로 재학습하고 코드 제출 ZIP을 만든다.
