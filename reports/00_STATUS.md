## 0. 판정 기준 (라운드 23 확정 — 이것이 슬롯 사용의 유일한 관문)

> **슬롯은 `ΔScore` 를 LB 앵커 닫힌식으로 계산할 수 있는 후보에만 쓴다.**

| | 요건 |
| --- | --- |
| **G1** | 모델 형식이 **검증**됐다 — 근사가 아니라 항등식 |
| **G2** | 2차항(곡률)이 **라벨 없이** 측정된다 |
| **G3** | 1차항(방향)이 **같은 층의 LB 실측점**에서 역산된다 |
| **G4** | 예측이 뒤집히는 데 필요한 `C` 배율이 **실측 전이오차 1.41× 를 넘는다** |

**근거 — 사전 근거 유형이 결과를 완전히 가른다 (표본 7건, 섞인 사례 0건).**

```
LB 앵커 닫힌식   3건   오차 7.4% / 상한충족 / 4.7%   — 전부 낙관 방향
홀드아웃 기반    0/4   배율 0.18 ~ -2.09,  부호 2회 오류
```

⚠️ **"3/3 오차 ≤5%" 가 아니다.** 셋 중 순수한 사전 점 예측은 없다 — 하나는 두
성분의 합, 하나는 상한, 하나는 산술이 사후다. **`hj12` 가 첫 순수 사전 검정이다.**
그리고 `C` 를 라벨없이 재면 실제 test 에서 **40% 과대**로 나온다(§10-3 실측 0.711) —
G4 는 이 전이오차를 봉투로 씌워 판정한다.

**홀드아웃(`fold` 스윕 · 위약 · 마스킹)은 후보 발굴 전용이다. 판정에 쓰지 않는다** —
평가 시즌이 챔피언의 in-sample 이라 전부 G2 를 위반한다. `hj11` 은 양 fold 가 우리
역사상 최대 신호(+16.5/+21.9)였는데 LB **−1.25** 였고, 같은 축의 LB 앵커는 −1.198 을
맞혔다(오차 4.7%).

**대가**: 신규 축은 LB 점이 0개라 G3 을 원리적으로 못 채운다 —
`gap_reverse`(+8.68) 같은 이득은 이 기준으로 못 잡는다. **기준의 목적은 최대 이득이
아니라 음수 회피다.**

상세: [`12_axis_reopening_report.md`](12_axis_reopening_report.md) §23.

### 슬롯 사용 전 체크리스트

**검증은 두 층이다. 1층은 확실해질 수 있고, 2층은 원리적으로 못 한다.**

**전 과정이 `tools/gate_check.py` 한 명령으로 돌아간다** (라운드 24).

#### 1층 — 빌드 검증 (결정론. 전부 통과해야 태운다)

예측이 아니라 확인이다. "zip 이 의도한 대로 동작하는가"만 본다. **하나라도 실패하면 중단.**

| # | 항목 | 합격 조건 | 도구 |
| --- | --- | --- | --- |
| 1 | 변경 격리 | 의도한 파일만 상이 (개수를 명시) | 빌더가 출력 |
| 2 | 레벨 재보정 | 재보정 후 프록시 Δmean ≈ 0 (`<1e-8`) | 빌더가 출력 |
| 3 | `meta.json` | **0/20** 어긋남. **반드시 마지막에 재생성** | `fix_meta.py` |
| 4 | zip 무결성·구조·파일명 | CRC 정상 · 래퍼폴더 없음 · 30자 이하 | `verify_zip.py` |
| 5 | 격리 실행 | 빈 임시 디렉터리에서 end-to-end 성공 | `verify_zip.py` |
| 6 | 추론 시간 | 600s 대비 여유 | `verify_zip.py` |
| 7 | 출력 형식 | 컬럼·행수·`row_id` 순서 일치·[0,1]·NaN 없음 | `verify_zip.py` |
| 8 | 행 독립성 | **챔피언 자신의 값과 같은 자릿수** (현재 ~5e−09, BLAS 누적) | `verify_zip.py` |

역검정: `hj11`(−1.25) · `hj07`(−5.93) · `hj10`(−0.58) 을 전부 2층에서 기각하고
`hj12` 만 통과시킨다. **같은 도구가 `gap_reverse`(+8.68) 도 기각한다 — 설계된 대가다.**

> ⚠️ 8번은 절대값이 아니라 **챔피언 대비**로 읽는다. 챔피언이 5.214e−09 를 내고
> 1140.92 를 받았다. 새 빌드가 같은 자릿수면 우리 변경의 결함이 아니다.

#### 2층 — 점수 예측 (확실해지지 않는다. 크기만 잰다)

**단 하나의 질문으로 줄인다.**

> **"이 후보가 지려면, 무엇이, 얼마나 틀려야 하는가?"**
> **한 문장으로 답할 수 있으면 태운다. 못 하면 안 태운다.**

| 답할 수 있나 | 예 |
| --- | --- |
| ✅ 답한다 | 라우팅 `hj12` — *"`C` 가 실측 전이오차(1.41×)의 1.8배로 틀려야 진다"* |
| ✅ 답한다 | `count4` β1.75 — *"`C=4.79` 가 틀려야 이긴다"* → 안 태웠어야 했다 |
| ❌ 못 한다 | `hj07_tmresid` — 홀드아웃 z 2.67 이 왜 전이되는지 기전이 없었다 → **−5.93** |
| ❌ 못 한다 | `hj11` fold 신호 +16/+22 — 왜 그 크기가 test 로 가는지 설명 불가 → **−1.25** |

**이 질문에 답하려면 G1~G4 가 필요하다.** 게이트는 별개 규칙이 아니라 이 질문에
답하기 위한 최소 재료다.

```
G1 형식 검증  ->  "무엇이" 를 특정할 수 있게 한다 (틀릴 수 있는 항이 유한개)
G2 라벨없는 곡률 -> 2차항을 in-sample 오염 없이 준다
G3 LB 앵커     ->  1차항을 test 자신에서 준다
G4 봉투        ->  "얼마나" 를 숫자로 만든다
```

#### 결정

`max` 채점이라 **하방은 슬롯 한 장뿐**이다. 그래서 2층은 채택/기각이 아니라
**슬롯 배분** 문제다.

```
1층 전부 통과  +  2층 질문에 답 가능  ->  가장 큰 후보부터 태운다
1층 실패                              ->  절대 안 태운다
2층 답 불가                           ->  다른 후보가 없을 때만, 클래스 전적을 근거로
```

## 5. 반복해서 값을 낸 규칙

**① 남의 종결을 인용하기 전에 그 실험의 팔 정의를 직접 연다.**
결론 문장이 아니라 코드의 `dict(...)` 를 본다. 대조군과 두 개 이상 다른 팔은 그 축을
판정할 자격이 없다 — 이긴 성분과 진 성분이 상쇄된다.
→ `ablate17` 의 `emb8` 이 4중 교란으로 닫혀 있었고, 풀었더니 **+7.67** 이었다.

**② 유의성 미달은 "효과 없음" 이 아니라 "표본 부족" 일 수 있다.**
가르는 것은 평균이 아니라 **SE** 다.
→ 콜드스타트 5시드 t 1.42 (기각 직전) → 15시드 t 18.94. 평균은 거의 불변. **+3.3 을 얻었다.**

**③ 규모를 먼저 계산하고 제안한다.** 곡률과 건수가 이미 저장소에 있는 경우가 많다.
→ `mlp_alpha` 재적합과 홀드아웃 규칙 수정을 이 순서로 자기기각했다.

**④ 무결성 수치는 대조군과 함께 보고한다.**
→ 행 독립성 4e−09 은 패치가 만든 게 아니라 원본에도 있었다(BLAS 배치 효과).

**⑤ 위약 없이 셀을 잘게 나누면 자유도만으로 점수가 오른다.**
→ 트랙맨 상황 셀의 오라클 +30.84 중 92% 가 미래 참조였다.

**⑪ 종결에는 베이스를 함께 적는다.** "닫혔다" 는 "그 베이스에서 닫혔다" 의 줄임말이다.
다시 열려 점수를 낸 종결이 셋이다 — emb8 +7.67 · 라우팅 +1.26 · `gap_reverse` +8.68 (라운드 22).

**⑫ 같은 베이스에서 잰 값끼리만 비교한다.** 다른 베이스의 fold 값과 LB 를 나란히 놓고
결론을 냈다가 판정 기준을 반대로 뒤집을 뻔했다 (§22-5).

**⑬ 믿을 만한 홀드아웃이 없다 — 판정 기준 넷이 전부 한 번씩 틀렸다.**
양 fold 일치 게이트(`gap_success` 를 기각했을 것) · `fold2024` 단독(2/3, 크기 배율 40배
산포) · `fold2023` 단독 · 위약 검정(`hj07` 이 z 2.67 통과 후 LB −5.93).
**결정을 홀드아웃이 아니라 슬롯 경제로 옮긴다** — 채점이 max 라 비용은 슬롯 하나이므로
물어야 할 것은 "통과했나" 가 아니라 **"이 슬롯을 여기 쓰는 게 나은가"** 다 (§22-6 ⑤).

**⑨ 계측기의 함수족이 가설의 함수족을 담아야 한다.** 단변량 t 검정으로 0/33 을 얻고
"신호 없음" 이라 했는데, 다변량 트리로는 z 2.67 이 나왔다. **그리고 그 z 2.67 도 LB 를
못 맞혔다** — 위약 통과가 배포 성공을 뜻하지 않는다 (라운드 21).

**⑩ in-sample 잔차 위에서 잔차 모델을 학습하지 않는다.** 두 fold 가 모두 in-sample 이면
"전이" 가 암기의 전이일 수 있다. fold 모델 잔차가 필수다 — 건너뛴 대가가 −5.93 이었다.

**⑦ 붙일 수 있는 키를 먼저 센다.** 트랙맨을 네 번 검토하며 매번 "무슨 값이 있나" 부터
물었다. 물어야 했던 것은 **"그 값을 test 행에 어떻게 붙이나"** 였다 — 1분이면 셌고,
그것으로 세 경로가 다 정해졌다 (§19-7).

**⑧ 남의 조언이 안 맞는 이유가 "틀려서" 는 아니다.** 막은 것은 **우리 베이스가 이미
포화**라는 사실이었다. 조언을 받을 때 **그쪽 베이스가 무엇이었는지**를 같이 묻는다.

**⑥ 전이 배율은 같은 축 안에서도 안 지켜진다.** `dim4→8` 2.13, `dim8→12` 0.18.
배율이 튄 측정은 **SE 가 컸던 측정**이다. 계측기를 조이면 배율도 안정된다
(콜드스타트 SE 0.49 → 배율 0.59~0.77, 원우 밴드 안).
